# State Affordability Dashboard

State Affordability Dashboard is an Android app built with **Jetpack Compose** that helps users explore and compare the affordability of U.S. states. Users can view minimum wage and 
median housing costs for each state. The app also includes filtering options to search by state name, wage level, or housing cost.

---

## Features

- **Home Screen**: Displays all U.S. states in a two-column grid of cards.
- **State Cards**: Each card shows:
  - State name
  - Minimum wage
  - Median housing cost
- **Filters**:
  - Search by state name
  - Filter by minimum wage
  - Filter by maximum housing cost
- **Navigation**: Click on a state card to view detailed state information.
